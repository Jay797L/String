# String (s21_string+)

Собственная реализация библиотеки **string.h** — расширенная версия стандартных функций работы со строками на языке C, а также собственные реализации `sprintf`, `sscanf` и доп. функций работы со строками. Проект в рамках **School 21 / C_Bootcamp**.

## О проекте

Библиотека воспроизводит поведение стандартной `string.h`, дополняя её форматным вводом-выводом и функциями в стиле C# `String` class. Все функции имеют префикс `s21_`.

## Структура проекта

```
String/
└── src/                        # Исходный код
    ├── s21_string.h /.c        # Стандартные функции string.h
    ├── s21_sprintf.h /.c       # Собственная реализация sprintf
    ├── s21_sscanf.h /.c        # Собственная реализация sscanf
    ├── s21_sspf.h /.c          # Бонусные функции работы со строками
    ├── Makefile                # Сборка
    └── tests/                  # Модульные тесты (Check)
        ├── s21_tests.c                 # Запуск всех тестов
        ├── s21_tests_string.c          # Тесты string.h
        ├── s21_tests_sprintf_main_part.c # Тесты sprintf
        ├── s21_tests_sscanf.c          # Тесты sscanf
        └── s21_tests_csharp.c          # Тесты бонусных функций
```

## Реализованный функционал

### Стандартные функции string.h (15 шт.)
- `s21_memchr`, `s21_memcmp`, `s21_memcpy`, `s21_memset`
- `s21_strlen`, `s21_strncat`, `s21_strchr`, `s21_strncmp`, `s21_strncpy`
- `s21_strcspn`, `s21_strerror`, `s21_strpbrk`, `s21_strrchr`, `s21_strstr`, `s21_strtok`

`strerror` учитывает платформу (Linux/macOS) через условную компиляцию.

### Форматный вывод — `s21_sprintf`
- Спецификаторы: `c d i f s u g G e E x X o p n %`
- Флаги: `- + (пробел) # 0`
- Ширина (число и `*`), точность (`.<число>` и `.*`), модификаторы длины `h l L`

### Форматный ввод — `s21_sscanf`
- Полная поддержка спецификаторов формата, ширины, модификаторов длины
- Научная нотация, восьмеричные/шестнадцатеричные/десятичные числа, указатели, подавление ввода (`*`)

### Бонусные функции (аналог C# String)
- `s21_to_upper` — перевод в верхний регистр
- `s21_to_lower` — перевод в нижний регистр
- `s21_insert` — вставка подстроки в заданную позицию
- `s21_trim` — удаление указанных символов по краям строки

## Сборка и тесты

Из каталога `src`:

```bash
make            # сборка статической библиотеки s21_string.a
make test       # запуск модульных тестов
make gcov_report # отчёт о покрытии кода (lcov)
make linter     # форматирование кода (clang-format, Google style)
make clean      # удаление сборочных файлов
```

Требуется компилятор `gcc` (-std=c11) и библиотека `Check` для тестов.
